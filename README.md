这是安卓 App《这个女巫在说梦话吧》的 PWA 网页版——**不用下载、不用安装**，浏览器打开就能用，iPhone/安卓/电脑全平台通用。

**在线使用**：https://flamingocheers.github.io/witch-web/

## ✨ 特性

- **六门术数，浏览器里算**：紫微斗数（iztro）、西方占星（astronomy-engine 天文级精度）、六爻（64卦全量装卦表）、梅花易数、塔罗牌（78张韦特）、雷诺曼卡（36张）
- **离线可用**：Service Worker 全量缓存，断网也能起卦排盘，只有 AI 解读需要联网
- **自带 AI Key**：填入你自己的 API Key（DeepSeek / OpenAI / Claude / Gemini / Kimi / 智谱 / 通义 / 豆包），请求由浏览器直连服务商
- **隐私优先**：无后端、无埋点。聊天记录、生辰、API Key 全部只存在你设备的浏览器里
- **千禧风 UI**：星云夜空、蝴蝶飞舞、流光边框，支持自定义背景图与模糊度

## 📱 加到主屏幕（推荐）

- **iPhone**：Safari 打开 → 分享按钮 → 「添加到主屏幕」→ 像原生 App 一样全屏使用
- **安卓 / 电脑**：地址栏出现「安装」图标时点击即可
